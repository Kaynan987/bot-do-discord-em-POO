# 🤖 Bot Discord - POO Kaynan é Lindo

Este é um bot para Discord desenvolvido com foco em **Programação Orientada a Objetos (POO)**, utilizando os quatro pilares principais: **abstração, encapsulamento, herança e polimorfismo**. O projeto foi criado como trabalho acadêmico e possui uma estrutura modular, comandos interativos, controle de música e muito mais.

## 🧩 Funcionalidades

- Sistema de música com fila, pausa, pular e stop
- Interface com botões e modais interativos
- Comandos organizados por categorias
- Uso de herança e polimorfismo em classes
- Estrutura com mais de 10 classes públicas
- Integração com `yt-dlp` e (opcionalmente) Spotify

---

## 📁 Estrutura do Projeto

bot-discord-POO-KAYNAN-e-lindo/
│
├── comandos/ # Módulos de comandos organizados por categoria
├── handlers/ # Manipuladores de eventos e comandos
├── music/ # Sistema de música (fila, player, etc.)
├── painel/ # Botões e interfaces do painel de controle
├── utils/ # Utilitários auxiliares
├── main.py # Arquivo principal para iniciar o bot
└── requirements.txt # Bibliotecas necessárias


---

## ⚙️ Pré-requisitos

- Python 3.10 ou superior
- Conta no Discord com permissão para criar um bot
- Token do bot (disponível no Discord Developer Portal)
